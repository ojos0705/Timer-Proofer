CHANGES
1. PWA/browser Picture-in-Picture:
   - Retains desktop Document Picture-in-Picture where supported.
   - Adds a canvas-backed muted-video PiP path for browsers that support
     HTMLVideoElement.requestPictureInPicture(), including Chrome Android.
   - Keeps the in-app mini widget as a fallback where system PiP is unavailable
     or a browser rejects the PiP request.
   - PiP button toggles the active PiP/mini surface closed.
2. Back handling while countdown runs:
   - Removes beforeunload confirmation that caused the browser prompt
     “Leave this page/site?”.
   - Persists the absolute timer state on pagehide.
   - Adds a browser history guard while the countdown is active.
   - Native Capacitor Back enters native PiP or minimizes the Activity on failure.
   - Android PiP params are prepared for automatic entry on supported OS versions.
3. Article detail:
   - Existing article modal is portaled to documentElement while active.
   - Full viewport sizing, topmost z-index, internal vertical scrolling, and safe areas.
4. Onboarding and Welcome:
   - Adds a repeatable QA preview query flag.
   - Preview reset clears only preview sessionStorage keys, not Supabase session,
     localStorage auth data, or actual first-visit completion flags.
   - Welcome slider supports pointer/touch horizontal swipe.
