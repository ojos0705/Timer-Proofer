Impor Midtrans Payout Report (CSV)

Unduh report dari Midtrans, ekstrak arsip 7z di perangkat Anda, lalu pilih file CSV. Parser memetakan kolom berdasarkan header; baris yang tidak memiliki biaya valid akan ditolak. XLSX belum didukung pada tahap ini.

Biaya yang cocok dengan Order ID akan dialokasikan ke paket. Biaya tanpa Order ID tetap dicatat sebagai belum teralokasi dan tidak dibagi rata secara asumtif.
