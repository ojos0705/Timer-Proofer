Changes
- Keep Welcome Screen unchanged.
- Make the Login/Register panel edge-to-edge on narrow mobile WebViews to remove unused top/bottom strips. Safe-area spacing is applied inside the panel; its own vertical scroll handles short viewports/keyboard resizing.
- Retain a constrained, centered auth panel on wider screens.
- Replace the Cloud Translation/Billing dependency with the free MyMemory provider through the authenticated Vercel route /api/translate.
- The provider requires no Google API key, no Google Cloud Billing, and no payment card.
- Default anonymous allowance follows MyMemory's documented 5,000 characters/day. Optional MYMEMORY_CONTACT_EMAIL can raise the documented limit to 50,000 characters/day.
- Keep language candidates local; do not make an extra language-catalog network request. Provider support is validated at actual translation time.
- Keep user-authored recipe/profile content excluded from auto translation.
- Align browser batch size with the backend/provider byte and character limits; split long UTF-8 text safely and preserve whitespace.
- Clarify unsupported-pair, quota, login, route, WebView-network, provider-network, and timeout failures.
- Map additional MyMemory provider language-selection errors to unsupported-pair responses.
