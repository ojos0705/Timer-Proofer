CHANGES
1. Settings alarm preview now has a separate playback lifecycle.
2. Save Preferences stops the preview immediately before closing the modal.
3. Turning off app sound stops the preview immediately.
4. Preview cancellation uses a generation guard so a delayed rejected play() promise cannot restart a beep.
5. Real proofing completion alarm playback remains separate and is not stopped by the Save Preferences preview cleanup.
6. Capacitor Android is restricted to the native Activity PiP surface. Browser video/document PiP routes are not opened in native mode.
7. PWA/browser PiP behavior remains unchanged.
